**DecentrlAI Investigator** is an operational investigation platform designed for automated intelligence gathering, data correlation, and multi-agent analysis. 

## 🎯 Core Objectives
*   **Decentralized Analysis:** Leverage local LLMs to process sensitive investigation data without relying on external APIs.
*   **Multi-Agent Orchestration:** Deploy specialized agents for data scraping, entity extraction, and relationship mapping.
*   **Extensible Architecture:** Built to easily integrate custom scripts, hardware inputs, and localized datasets.

## ⚙️ Tech Stack
*   **Backend / Orchestration:** Python, LangGraph
*   **Local AI Models:** Ollama integration (Llama 3, Mistral)
*   **Frontend UI:** React, TailwindCSS
*   **Database / Storage:** (TBD - e.g., PostgreSQL / Vector DB)
